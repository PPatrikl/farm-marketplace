# farm-marketplace
Suomenkielinen verkkosovellus, joka yhdistää maanviljelijät, kausityönhakijat ja luonnontuotteiden kerääjät yhdelle alustalle.

## Projektin tavoite

Rakentaa MVP-verkkosovellus, jonka avulla:

- Maanviljelijät voivat julkaista itsepoiminta- ja työpaikkailmoituksia
- Työnhakijat voivat löytää kausityötä
- Luonnontuotteiden kerääjät voivat myydä tuotteitaan

## Teknologiat
